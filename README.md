# 📊 Telco Customer Churn Analysis Dashboard
![dashboard](powerbi%dashboard.png)
Overview

This project analyzes telecom customer churn behavior using SQL and Power BI. The objective is to identify customer retention patterns and factors contributing to customer churn.

Tools Used

* SQL (MySQL)
* Power BI
* Excel

Key Metrics

* Total Customers: 7043
* Churned Customers: 1869
* Churn Rate: 26.54%

Dashboard Features

* Total Customers KPI
* Churned Customers KPI
* Customer Churn Distribution
* Contract Type vs Churn
* Internet Service vs Churn
* Gender vs Churn
* Payment Method vs Churn

Key Insights

* Month-to-month contract customers have the highest churn.
* Two-year contract customers have the lowest churn.
* Fiber Optic users show higher churn.
* Electronic Check users are more likely to churn.
* Gender has minimal impact on churn behavior.

Project Files

* Power BI Dashboard (.pbix)
* SQL Analysis Queries
* Business Insights Report
* Dashboard Screenshots

Business Impact
This dashboard helps identify high-risk customer segments and supports customer retention strategies.
